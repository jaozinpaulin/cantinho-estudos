# Cantinho

> Seu espaço pessoal e minimalista para estudos de idiomas baseados em _input_ real (músicas, filmes e séries).

## Sobre o Projeto

O **Cantinho** nasceu da vontade de fugir dos aplicativos tradicionais e engessados de idiomas. A ideia é transformar anotações soltas de trechos consumidos no dia a dia em um processo ativo de aprendizado: capturar, lapidar, associar visualmente e treinar com contexto real.

Inspirado na atmosfera aconchegante e intimista de jogos como _Coffee Talk_, o design prioriza a leitura calma, tons terrosos e uma interface limpa e autoral.

## Tecnologias Utilizadas

- **Next.js (App Router)**
- **TypeScript**
- **Tailwind CSS (v4)**
- **Lucide React** (Ícones minimalistas)
